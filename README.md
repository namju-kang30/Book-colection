# 진로 맞춤형 차시별 독서 활동 일지 (Realtime Reading Log Platform)

학생들이 자신의 희망 진로 계열(자연과학, 공학, 인문사회, 의약보건 등)을 선택하고, 활동 차시별로 독서 일지를 간편하게 작성·공유할 수 있는 모바일/데스크톱 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 특징 및 기능

### 1. 학생용 기능 (Student Portal)
- **진로 계열 & 차시별 필터링:** 8대 핵심 진로 계열별(자연과학, 공학·IT, 인문·사회, 의약·보건, 교육·사범, 경영·경제, 예술·체육, 융합·자율) 뱃지 및 차시 필터
- **공통 양식 동적 렌더링 폼:** 교사가 설정한 최신 양식(도서명, 저자, 읽은 범위, 인상 깊은 구절, 진로 연계 통찰, 별점 등) 자동 로드
- **실시간 피드 & 상세 보기:** 작성된 일지를 카드 그리드로 열람, 전문 상세 보기 모달, 인쇄 및 공감(좋아요) 반응
- **작성 편의성:** 최근 입력한 학번/이름 자동 기억, 작성 완료 시 축하 폭죽 애니메이션 & 즉각 피드 갱신

### 2. 선생님 / 관리자 모드 (Admin Dashboard)
- **보안 관리자 인증:** 코드 내 평문 암호를 노출하지 않는 **SHA-256 단방향 암호화 해시 검증** 방식 적용
- **독서일지 양식 빌더 (Template Builder):** 질문 항목명, 입력 형태(단문/장문/별점/숫자), 필수 여부, 안내문구(Placeholder)를 시각적으로 추가/수정/삭제/순서변경
- **일지 통합 관리 & Excel 다운로드:** 전체 제출 일지 조회, 개별 삭제, **Excel(.xlsx) 및 CSV 일괄 다운로드**
- **진로 계열 관리:** 진로 계열 추가, 색상/아이콘 지정, 삭제
- **활동 차시 관리:** 활동 차시명, 활동일자 등록, 활성화/마감 토글
- **Supabase 원클릭 연동:** 접속 키 설정, 연결 상태 진단, **SQL 스키마 원클릭 복사**

## 🚀 빠른 시작 방법

### 방법 1. 원클릭 실행 (Windows)
`start.bat` 파일을 더블 클릭하여 실행하면 로컬 서버가 구동되고 브라우저(`http://localhost:3000`)가 자동으로 열립니다.

### 방법 2. 파이썬 터미널 실행
```bash
python run_server.py
```
브라우저에서 `http://localhost:3000` 으로 접속합니다.

## 🗄️ Supabase 클라우드 데이터베이스 연동 가이드

기본 상태에서는 브라우저 **LocalStorage(모의 모드)**로 즉시 작동하므로 키가 없어도 모든 기능을 테스트할 수 있습니다.  
실제 학교 또는 학급 전체 학생들이 실시간으로 공유하게 하려면 아래 절차를 진행하세요:

1. [Supabase](https://supabase.com)에 로그인하고 무료 프로젝트를 생성합니다.
2. 좌측 메뉴의 **SQL Editor**로 이동합니다.
3. 본 프로젝트의 `supabase_schema.sql` 파일 내용(또는 관리자 화면의 **[SQL 전체 복사]** 버튼 내용)을 붙여넣고 **[Run]**을 실행합니다.
4. Supabase **Project Settings -> API**에서 아래 2개 값을 복사합니다:
   - `Project URL`
   - `Project API Keys`의 `anon` (public) 키
5. 웹앱 상단의 **[로컬 모의모드]** 또는 관리자 화면의 **[Supabase 연동 & SQL]** 탭에 입력하고 **[설정 저장 및 연동]**을 누르면 실시간 클라우드 DB 연동이 완료됩니다!
